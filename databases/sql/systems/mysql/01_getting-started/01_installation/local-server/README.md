# Databases - MySQL - Getting Started - Installation - Local Server

Created: Tuesday, March 31, 2026 | Last Updated: Tuesday, March 31, 2026

To install a local MySQL server instance, download the MySQL Community Server from [MySQL Community Downloads](https://dev.mysql.com/downloads/).
I recommend downloading the LTS (long-term support) version, since this version will likely be supported in whichever production environment you choose to implement.
Be sure to select your correct operating system and operating system version.
