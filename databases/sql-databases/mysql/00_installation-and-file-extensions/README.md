# Databases - MySQL - Installation and File Extensions

Created: Tuesday, March 31, 2026 | Last Updated: Tuesday, March 31, 2026

To use MySQL, you must login to and acccess a running MySQL server, either on your local machine or through a remote network connection.

## Local Installation

To install a local MySQL server instance, download the MySQL Community Server from [MySQL Community Downloads](https://dev.mysql.com/downloads/).
I recommend dowloading the LTS (long-term support) version, since this version will likely be supported in whichever production environment you choose to implement.
Be sure to select your correct operating system and operating system version.

## Remote Database Server

You can create a remove MySQL server instance in many ways.
One way is to use an Infrastructure-as-a-Service provider, such as [DigitalOcean](https://www.digitalocean.com/), to create and manage a MySQL database server instance.
Please note that many of these services have associated costs with creating, running, and accesing a remote database.
Be sure to look at your service provider's pricing and fee structure before you start your project.
